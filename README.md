# Perros con razas, humanos sin ellas

Cápsula interactiva de Biología: un análisis comparativo entre las razas de perros y la idea de "razas humanas", para 16-18 años.

## Uso

- Abrir `index.html` en el navegador (mantener la carpeta `img/` junto al archivo).
- Todos los bloques de texto tienen botón **Escuchar**: lectura en voz alta con una voz alegre latinoamericana (español de México). Si el navegador no tiene una voz `es-MX` instalada, usa la voz en español más cercana con `lang="es-MX"`.
- Las carpetas se abren en orden; el progreso se guarda en `localStorage`.
- Modo docente: engranaje en el pie de página, PIN `2026` (no persiste al recargar).

## Estructura

- `index.html` — la cápsula completa (HTML + CSS + JS, sin dependencias externas).
- `img/` — imágenes IMG-01 a IMG-09 (webp + jpg) y `logo.png`. Se pueden reemplazar conservando los nombres.
